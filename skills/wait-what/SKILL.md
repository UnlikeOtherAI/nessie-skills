# Wait What?

Restate an unclear answer with the context and plain language the reader needs to understand it.

## Rebuild the explanation

1. Read the user's response and the previous answer. Identify what the answer was trying to communicate, the unexplained terms, and any skipped connection between evidence and conclusion.
2. Give one sentence of context, then state the answer directly. Explain what changed, what it means for the person, and any action they need to take.
3. Replace unexplained jargon with familiar words. Keep project vocabulary when it is necessary, and define it with a concrete example. Use the relevant supplied glossary when available.
4. Add the missing causal or procedural step. A reader should not have to infer why a fact leads to the recommendation.
5. Check that the restatement preserves qualifications, numbers, and uncertainty. If the original answer was wrong, correct it and identify the correction plainly.

Return the new explanation, usually in a few connected paragraphs. Use a small example only when it resolves the confusion. Ask a focused question only if the meaning of the user's question remains unclear after using the available context. Do not repeat the same dense explanation with synonyms or promise that every later response will be simpler.
