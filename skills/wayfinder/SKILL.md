# Wayfinder

Plan a large effort by mapping the decisions and dependencies that must be settled before execution is clear.

## Build the decision map

1. Name the destination in one or two concrete sentences. State what would make planning complete and what lies outside the effort.
2. Read known decisions, constraints, evidence, and existing plans. Identify precise questions that are ready to investigate. Keep poorly understood future questions in a separate unresolved area instead of pretending to know every task now.
3. Give each decision a useful title, the question it resolves, prerequisite decisions, the evidence needed, and the person who owns it. Classify it as research, prototype, human decision, or enabling action where that distinction helps assign work.
4. Order the currently unblocked decisions. Resolve prerequisite facts before dependent design choices. A human decision remains pending until the person decides; an agent cannot answer for them.
5. Record each resolution once with its evidence and public reason. Update the map's index with a short gist and a pointer. Add newly clarified questions and remove stale assumptions as the route changes.
6. Recheck the destination and scope after material decisions. Keep consciously excluded work separate from still-unclear work. Planning ends when execution can proceed with explicit ownership and completion criteria.

Use an existing authorized document or tracker. An inline map is sufficient when tracker writes are unavailable or unnecessary. Publishing issues, assigning people, launching research agents, provisioning access, or performing implementation requires authority already present in the task. Deliver the map, decisions so far, remaining dependencies, and the next useful decision. Do not create a large ticket hierarchy for a small, already understood task.
